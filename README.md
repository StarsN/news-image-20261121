One image summing up the world news of Saturday 21 November 2026, drawn
from the full day's reporting: Russia's biggest strike of the war on
Ukraine, with missiles landing in Poland, and the double-tap attack on
Kryvyi Rih that followed; the capture of FBI most-wanted cartel boss
"El Chapo Isidro" in Sinaloa; COP31 running into overtime in Antalya with
no deal and fossil fuels cut from the draft; an AI sell-off dragging the
S&P 500 and the Dow into correction; a pancreatic-cancer pill leaving
tumours undetectable in one in twelve patients; BepiColombo slipping into
orbit around Mercury after eight years; Gen Z protests across 25 European
countries; and more — the FBI crime database hack, Houthi missiles fired
on Riyadh, a 6.7 earthquake in Peru, GTA VI's $3.8bn first day, Bitcoin
bouncing back above $60,000 and Bayer's $7.25bn Roundup settlement.

The image is drawn from scratch by `compose.py` (Pillow, no network, no
downloaded assets) and copied to the output directory by `main.py`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

To redraw the front page:

```sh
python3 compose.py
```
